# Masters Letter of Award - Implementation Documentation

## Overview

The Masters Letter of Award feature is a professional document generation system for Mutesa I Royal University designed to award Master's degree recipients. It is seamlessly integrated into the existing Certificate management system and follows the same best practices used for undergraduate and postgraduate certificates.

## Architecture

### Components

1. **TranscriptDocumentCentre.ascx** - Main UI control
   - Located in: `UserControls/Registry/TranscriptDocumentCentre.ascx`
   - Provides the interface for selecting documents and generating reports
   - Includes minimalist popup for Masters Letter configuration

2. **TranscriptDocumentCentre.ascx.cs** - Code-behind logic
   - Located in: `UserControls/Registry/TranscriptDocumentCentre.ascx.cs`
   - Handles data retrieval and report generation
   - Method: `cmdGenerateMastersLetter_Click()` - Core generation logic

3. **MastersLetterOfAward.cs** - XtraReport report class
   - Located in: `App_Code/XtraReports/MastersLetterOfAward.cs`
   - Professional A4-formatted report with university branding
   - Implements automatic date calculation and data binding

4. **Default.aspx** - Report viewer
   - Located in: `COOPERP/XtraReports/Default.aspx`
   - Displays the generated Masters Letter in web browser
   - Provides print, save, and export functionality

## How It Works

### Data Flow

```
1. User selects student from grid
2. User selects "Masters Letter of Award" from Document dropdown
3. User clicks "Print Documents" button
4. Masters Letter popup appears
   ├─ Honours/Distinction field (optional)
   ├─ Reference Number field (optional)
   └─ Generate button
5. System captures:
   ├─ Student data from grid (name, registration, degree)
   ├─ Dates from graduation info (completion date, graduation date)
   ├─ Optional fields from popup (honours, reference number)
   └─ Auto-generates reference if not provided: MLA/[REGNO]/[YEAR]
6. Report is rendered with all data
7. User can view, print, or download in various formats
```

### Data Captured

#### Automatic (from database):
- **Student Full Name** - acad_GetBatchStudentTranscriptData.name
- **Registration Number** - acad_GetBatchStudentTranscriptData.regno
- **Degree Name** - acad_GetBatchStudentTranscriptData.deg
- **Completion Date** - From graduation setup (formatted to "dd MMMM, yyyy")
- **Graduation Ceremony Date** - From graduation setup
- **University Name** - acad_university.name
- **Document Serial Number** - For verification purposes

#### Optional (from popup):
- **Honours/Distinction** - e.g., "With Distinction", "With Merit"
- **Reference Number** - If not provided, auto-generated as MLA/[REGNO]/[YEAR]

#### Generated by System:
- **Letter Date** - Current date in format: "dd MMMM, yyyy"
- **Senate Approval Date** - Completion date from student record
- **Verification QR Code** - Links to https://verify.mru.ac.ug/masters?serial=[DOCNO]

## Report Features

### Professional Branding
- **University Name**: Prominently displayed in corporate blue (RGB 31, 78, 121)
- **Logos**: Left and right logos from certificate resources
- **Decorative Elements**: Top border line and dividing lines in corporate colors
- **Subtitle**: "Academic Awards Registry" for formal appearance

### Content Sections
1. **Header** - University logos and name
2. **Metadata** - Letter date and reference number
3. **Body** - Formal letter content
   - Greeting and student information
   - Degree name (prominent)
   - Honours/Distinction (if provided)
   - University name
   - Senate approval information
   - Graduation ceremony details
   - Closing statement
4. **Authorization** - Signature area and seal area
5. **Security** - Serial number, barcode, and QR code

### Security Features
- **Barcode**: Code 128 format with document serial number
- **QR Code**: Links to verification URL
- **Serial Number**: Printed for manual verification
- **Verification Footer**: Instructions for verifying authenticity

### Paper Format
- **Size**: A4 (210mm x 297mm)
- **Orientation**: Portrait
- **Margins**: 0.7" (approximately 18mm)
- **DPI**: 254 DPI for professional printing
- **Font**: Calibri for consistency with other university documents

## Usage Instructions

### Generating a Masters Letter

1. **Navigate to Certificate Management**
   - Go to Admin → Registry → Transcript Centre

2. **Configure Graduation Information** (if not already done)
   - Click "Set Graduation Info"
   - Enter Completion Date (Senate approval date)
   - Enter Graduation Date (Ceremony date)
   - Enter Convocation Title if applicable
   - Save

3. **Select Student**
   - Select student from the gridview by checking the checkbox
   - Ensure Certificate Status is "Ready" (not already printed)

4. **Select Document Type**
   - From "Document Name" dropdown, select **"Masters Letter of Award"**

5. **Click "Print Documents"**
   - The Masters Letter popup will appear

6. **Configure Optional Fields**
   - **Honours/Distinction**: Enter if applicable (e.g., "With Distinction", "With Merit")
   - **Reference Number**: 
     - Leave blank for auto-generation (format: MLA/[STUDENT_ID]/[YEAR])
     - Or enter custom reference number if required

7. **Generate Letter**
   - Click "Generate Masters Letter"
   - Confirm action in popup
   - Letter will be rendered in the viewer

8. **Print or Export**
   - Use the toolbar to:
     - Print directly to printer
     - Save to PDF
     - Export to other formats (Excel, Word, etc.)
     - Download to disk

### Best Practices

- **Honours Field**: Only fill if the graduate has received specific honors or distinctions. Leave blank for standard awards.
- **Reference Number**: Generally leave blank to allow the system to auto-generate consistent references.
- **Dates**: Ensure graduation information is set before generating letters using "Set Graduation Info".
- **Verification**: The QR code on the letter links to the university's verification portal.

## Security & Verification

### Document Verification

Each Masters Letter includes:
1. **Barcode** - Machine-readable document identifier
2. **QR Code** - Scannable link to verification page
3. **Serial Number** - For manual verification
4. **Official Seal Area** - For physical stamp/emboss

### Verification URL Format
```
https://verify.mru.ac.ug/masters?serial=[DOCUMENT_SERIAL]
```

## Customization

### Modifying the Report

To customize the Masters Letter report:

1. Open: `App_Code/XtraReports/MastersLetterOfAward.cs`
2. Modify properties:
   - **Colors**: Change `RGB(31, 78, 121)` to different values
   - **Fonts**: Modify Calibri to another font
   - **Logos**: Replace image resources from Certificate.resx
   - **Positioning**: Adjust LocationFloat and SizeF values
   - **Text**: Modify label text in BeforePrint events

3. Compile and test

### Modifying the Popup

To customize the popup:

1. Open: `UserControls/Registry/TranscriptDocumentCentre.ascx`
2. Find the `pop_masters_letter` control around line 620
3. Add/remove fields or modify labels
4. Update the code-behind to handle new fields

## Troubleshooting

### Issue: "Masters Letter Already Printed"
- **Cause**: Certificate Status is not "Ready"
- **Solution**: Use "Reverse Status" button to reset, then try again

### Issue: Missing student data in letter
- **Cause**: Student record incomplete in database
- **Solution**: Ensure student graduation information is properly configured

### Issue: Barcode not printing
- **Cause**: Document serial number missing
- **Solution**: Ensure the certificate/document system has assigned a serial number

### Issue: QR code links not working
- **Cause**: Verification server not configured
- **Solution**: Contact IT to configure https://verify.mru.ac.ug/masters endpoint
